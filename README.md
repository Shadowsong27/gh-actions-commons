# gh-actions-commons

Composite actions for CI/CD workflows across Shadowsong27 repositories.

## Available Actions

_None currently._

> The former `opencode-review` action was retired (HARN-79). PR review is now the
> self-contained **pi.dev** reviewer, provisioned per-repo via the `setup-pi-review`
> skill (hl-knowledge-market warehouse) and inlined into each repo's
> `.github/workflows/pi-pr-review.yml` — no shared composite action.

## Contributing

Each action lives in its own directory with an `action.yml` and a local `README.md` for usage details.
